# 赛博祭祖 · Cyber Zhen Zu

数字化祭祖平台 — 传统仪轨与赛博朋克美学的融合。

```
npm install
npm run dev
```

---

## 功能概览

### ⛩️ 祭坛
中央祖宗牌位，支持切换祖先、灯笼动画、鸣钟、供桌上供

### 🔥 香火
选择檀香 / 沉香 / 艾草，Canvas 烟雾动画，60 秒燃烧计时，功德累计

### 🍎 供品
水果、清茶、清酒、糕点、鲜花、粽子，点击上供、再次点击撤供

### 💰 化纸
金元宝、银元宝、纸钱、纸衣服、纸房子，Canvas 火焰粒子动画，灰飞烟灭效果

### 🌳 家谱
- **姓氏自动提取**：从已有祖先姓名中识别姓氏，前端显示为 `陈氏` 徽章
- **添加先祖**：只需填写名字，姓氏自动拼接前缀
- **批量导入**：支持 CSV 文本和 JSON，可上传文件，预览后确认导入
- **导出 JSON**：一键导出备份
- 按代数（祖 / 考 / 妣）分组展示

### 📅 祭日
显示距下次祭日的倒计时，7 天内红色高亮，支持提醒开关

### 🎋 祈福
撰写祈福留言，支持家祭/私两类，Canvas 孔明灯漂浮动画，点灯祈福

### ✨ 祭祀大典
八步完整仪轨引导：**点香 → 献供 → 敬酒 → 上香 → 叩拜 → 鸣钟 → 化纸 → 祈福**，每步有描述和交互

## 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | React 18 + TypeScript |
| 构建 | Vite 8 |
| 样式 | Tailwind CSS v3 |
| 动画 | Framer Motion |
| 状态 | Zustand（localStorage 持久化） |
| 粒子 | Canvas API |

## 项目结构

```
src/
├── components/
│   ├── Altar/           # 祭坛主视图
│   ├── Incense/         # 香火焚烧
│   ├── Offerings/       # 供品管理
│   ├── PaperOfferings/  # 化纸焚烧
│   ├── FamilyTree/       # 家谱与导入
│   ├── MemorialDays/    # 祭日倒计时
│   ├── Prayers/          # 祈福板
│   ├── Ritual/           # 祭祀仪轨
│   └── shared/           # 侧边栏 / 粒子背景
├── store/               # Zustand 状态管理
├── types/               # TypeScript 类型定义
└── data/                # 示例数据
```

## 数据导入格式

**CSV**（每行一条）：
```
姓名,生年,卒年,代数(祖/考/妣),关系,简介
陈德福,1921,1998,祖,曾祖父,勤俭持家
陈建国,1948,2019,考,祖父,技艺精湛
```

**JSON**：
```json
[
  { "姓名": "陈德福", "生年": 1921, "卒年": 1998, "代数": "祖" },
  { "姓名": "陈建国", "生年": 1948, "卒年": 2019, "代数": "考" }
]
```
